# 📰 Blog Preview Card

![Project Screenshot](https://github.com/notramm/Blog-Preview-Card/blob/main/asset/Screenshot.png)

## 📖 Overview
**Blog Preview Card** is a simple and elegant HTML & CSS project that replicates a clean blog card design from a Figma file.  
It’s a perfect challenge for beginners looking to strengthen their understanding of **HTML structure**, **CSS styling**, and the **box model**.

---

## 💡 Features
- Responsive **HTML & CSS-only** design  
- Clean and minimal layout  
- Typography styled using **Figtree** font family  
- Perfect for learning **card layouts**, **shadows**, and **borders**

---

## 🛠️ Built With
- **HTML5**
- **CSS3**
- **Figma Design Reference**
